Privacy Policy: ww2-long

Last updated: October 29, 2026

ww2-long is a private tool that uploads World War II documentary videos to its owner's own YouTube channel through the YouTube API Services. It is used only by the channel owner.

  • Data we receive from Google: only an OAuth access token and refresh token for the owner's channel, with the scopes needed to upload videos, set thumbnails, captions and playlists, post the owner's pinned comment and read the channel's own video statistics. No data of other users is collected.
  • How it is used: only to publish and measure the owner's own videos.
  • Storage: tokens are kept as encrypted GitHub Actions secrets of the project. They are never shared, sold or used for advertising.
  • Deletion: revoke access at myaccount.google.com/permissions; the stored token then stops working and is deleted on request.
  • This tool uses the YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.
  • Contact: github.com/TerraIncognita001/ww2-long/issues
